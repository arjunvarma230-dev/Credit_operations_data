# Credit Operations MIS Dashboard

An interactive dashboard built using **Excel, Power Query, and Power BI** to analyse loan applications and monitor credit operations performance.

### Tools Used
- Microsoft Excel
- Power Query
- Power BI
- DAX

### Key Features
- Application status analysis
- City-wise loan amount tracking
- Analyst performance monitoring
- Average processing TAT
- Interactive dashboard filters

### Dataset
10,000+ simulated loan application records.

**Note:** This project uses mock data for learning and portfolio purposes.
